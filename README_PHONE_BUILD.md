# Sathi AI — Phone-only APK build

This project includes a GitHub Actions workflow that builds the debug APK in the cloud.

After uploading this project to a GitHub repository, open the repository's Actions tab, select **Build Sathi AI APK**, and tap **Run workflow**. When the build finishes, open the workflow run and download the **SathiAI-debug-apk** artifact.

The APK does not contain a Groq API key. Enter your own key inside the app Settings after installation.
